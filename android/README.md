# Sahm Download Manager (سهم) — Android Studio Project

Please refer to the main repository documentation at [../README.md](../README.md) for full instructions on building debug APKs, signing releases, creating Android App Bundles (AAB), and running automated unit tests.

### Quick Commands

```bash
# Run Unit Tests
./gradlew testDebugUnitTest

# Build Debug APK
./gradlew assembleDebug

# Build Release AAB (Requires keystore configured in keystore.properties or environment)
./gradlew bundleRelease
```
